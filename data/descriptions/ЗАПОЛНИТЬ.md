# Описания машин — запасной путь заполнения

Используется, только если не получилось выгрузить чат Telegram в JSON.
При экспорте чата этот файл не нужен: привязка описаний к фото берётся из выгрузки.

## Как заполнять

Под каждым заголовком вставь описание из Telegram **целиком, как есть** — с эмодзи,
переносами и ценой. Ничего вычищать не надо, разберу сам.

Каждая машина ниже уже опознана по фотографиям. Чтобы не перепутать похожие,
рядом стоят приметы: цвет, кузов и госномер с кадра. Сверяй по ним, а не по названию:
в парке две Elantra, два Rio и два Solaris.

Открой папку `public/cars/<id>/` — там все кадры этой машины, если нужно свериться глазами.
