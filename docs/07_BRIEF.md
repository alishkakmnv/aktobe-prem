# Aktobe Premium: ТЗ на редизайн для Claude Code

Сайт: премиум-авто с водителем в Актобе (клиент Бахыт). Репозиторий: `alishkakmnv/aktobe-prem`.
Задача: пересобрать лендинг по этому ТЗ, задеплоить превью, закоммитить и запушить.

Рядом лежит папка `reference/`: исходники макета из Claude Design (`Main.dc.html` для десктопа, `Mobile.dc.html` для мобайла 390, `Cards.dc.html` для карточек, `Motion.dc.html` для раскадровки анимаций). Это HTML с инлайн-стилями: верстку, отступы и тексты бери оттуда 1-в-1. Теги `<x-dc>`, `<sc-for>`, `{{…}}` и `/_blob/…` относятся к рантайму макета, их не копируй. Картинки бери из репо.

## 0. Как работать (порядок обязателен)

1. **Сначала разберись в репо.** Определи стек, где лежат фото машин, как сейчас собраны WhatsApp-ссылки, мета-теги, SEO и аналитика. Стек не меняй, если он не мешает (GSAP подключается к чему угодно).
2. **Работай в отдельной ветке `redesign`.** Не пушь в `main`: прод клиента не трогаем до подписания договора.
3. **Донор-своп, а не переписывание с нуля.** Меняем hero, карточки, палитру, типографику, шапку и добавляем новые секции. Сохраняем:
   - рабочую WhatsApp-логику (номер, предзаполненные тексты);
   - SEO: title, description, OG, canonical, структуру заголовков, аналитику и счётчики, если они есть;
   - все существующие URL и якоря.
4. **Данные не выдумывай.** Тексты, цены, машины и контакты бери из раздела 3. Если в репо данные отличаются от этого ТЗ, оставь те, что в репо, и выпиши расхождения в отчёт.
5. В конце: прогони grep-гейты (раздел 8), `build`, превью-деплой, коммит, пуш в `redesign`. Ссылку на превью выведи в конце.

### 2.7 Как это работает `#how` — «03 — Процесс»
4 шага в ряд (2×2 на ≤1024, столбик на ≤640). Сверху горизонтальная линия `#262A27`, которая заливается `#2E6B52` по скроллу. Шаг: точка 15px → номер (14px 700 `#8FB3A2`, активный становится `#2E6B52`) → H3 → текст 15px.
1. **Заявка**: «Выбираете машину на сайте или пишете в WhatsApp: дата, время, маршрут и сколько человек едет.»
2. **Подтверждение**: «Называем стоимость по часам целиком, без доплат в дороге, и закрепляем за вами водителя.»
3. **Подача**: «Автомобиль с водителем подаём по вашему адресу к назначенному времени. Круглосуточно.»
4. **Поездка**: «Едете пассажиром. Оплата наличными, картой или по QR. Продлить время можно прямо в поездке.»

## 5. Анимации: GSAP 3 + ScrollTrigger + SplitText + Flip, Lenis

Общие правила:
- Lenis `lerp: 0.1`, `lenis.on('scroll', ScrollTrigger.update)`.
- Всё внутри `gsap.matchMedia()`. Пины только в `(min-width: 768px)`.
- `prefers-reduced-motion: reduce`: только opacity за 0.3s, без движения.
- Анимируем только `transform`, `opacity` и `filter`. Прелоадера нет, hero собирается за ≤1.8s.

**Hero-таймлайн на загрузке:**
| t | Элемент | Код |
|---|---|---|
| 0.00 | машина | `from(car, { xPercent: -130, duration: 1.4, ease: 'expo.out' })` |
| 0.00 | тень | синхронно, `scaleX .6 → 1`, `opacity 0 → 1` |
| 1.25 | «кивок» на торможении | `to(car, { rotation: -0.6, yoyo: true, repeat: 1, duration: 0.18, transformOrigin: '30% 100%' })` |
| 0.20 | H1 | `SplitText(h1, { type: 'lines', mask: 'lines' })` → `from(lines, { yPercent: 100, duration: 0.9, stagger: 0.08, ease: 'power4.out' })` |
| 0.70 | CTA + инфо-строка | `from([cta, info], { y: 12, autoAlpha: 0, duration: 0.5, stagger: 0.1 })` |
| ~1.10 | плашка | `from(plate, { y: 24, autoAlpha: 0, duration: 0.6, ease: 'power3.out' }, '-=0.3')` |
| цикл | точка индикатора | `to(dot, { y: 28, duration: 1.5, repeat: -1, yoyo: true, ease: 'sine.inOut' })` |

**Скролл:**
| Что | Код |
|---|---|
| Шапка | `ScrollTrigger.create({ start: 'top -80', onUpdate: s => gsap.to(header, { yPercent: s.direction === 1 ? -120 : 0, duration: 0.35, ease: 'power2.out' }) })` |
| Пин hero (≥768) | `pin: true, pinSpacing: false, scrub: true`; машина `x: '12vw', autoAlpha: 0.3`; текст `y: -60, autoAlpha: 0`; манифест наезжает сверху |
| Машина (мобайл, без пина) | `to(car, { xPercent: 6, yPercent: 4, scrollTrigger: { scrub: true } })` |
| Заголовки секций | H2 по строкам из маски `yPercent 100 → 0`, 0.8s `power4.out`, `start: 'top 80%'`, `once: true`; черта надзаголовка `scaleX 0 → 1`, origin left, 0.6s |
| Манифест | `SplitText(p, { type: 'words' })` → `fromTo(words, { opacity: 0.2 }, { opacity: 1, stagger: 0.1, ease: 'none', scrollTrigger: { start: 'top 75%', end: 'bottom 45%', scrub: 0.5 } })` |
| Сетка автопарка | `ScrollTrigger.batch(cards, { start: 'top 85%', once: true, onEnter: b => gsap.from(b, { y: 30, autoAlpha: 0, duration: 0.7, stagger: 0.08, ease: 'power3.out' }) })` |
| Фильтр | `Flip.getState(cards)` → смена → `Flip.from(state, { duration: 0.5, ease: 'power2.inOut', absolute: true })`, вход и выход через fade |
| Bento | каскад как у автопарка |
| Условия | каскад ячеек |
| Шаги | линия `scaleX 0 → 1`, `scrub: 0.6`; на `top 60%` номер становится `#2E6B52`, текст opacity с 0.4 до 1 |
| Мобильная панель | `ScrollTrigger({ trigger: hero, start: 'bottom 80%', endTrigger: final, end: 'top bottom', toggleClass: { targets: bar, className: 'is-shown' } })`, CSS `translateY(100%) → 0` за 0.35s |

**Hover (на CSS):**
- текст-ролл: две копии текста в `overflow: hidden`, на hover сдвиг на `translateY(-100%)` за 0.35s с `cubic-bezier(.16,1,.3,1)`;
- кнопка: фон из прозрачного в `#2E6B52` за 0.3s;
- карточка: см. 2.4;
- FAQ: см. 2.8.

**Не делаем сейчас** (нужна фотосъёмка): стопку липких карточек, макро-паузы, горизонтальный пин автопарка.

## 6. Скорость, SEO, доступность
- Фото переведи в WebP/AVIF с `srcset` и `loading="lazy"` для всего ниже hero. Hero-PNG грузи с `preload`. Цель: Lighthouse mobile ≥ 90, CLS ≈ 0.
- SEO: текущее не ломай, только добавляй. JSON-LD `AutoRental` (`LocalBusiness`) с адресом, телефоном и часами `24/7` из раздела 3. OG-картинка с LX570. Если `sitemap.xml` и `robots.txt` нет, создай. У всех фото нужен `alt`.
- Доступность: контраст ≥ 4.5:1, кнопки ≥ 44px, видимый `:focus-visible` (обводка `#8FB3A2`), `aria-label` у иконочных кнопок, настоящие `<button>` и `<a>`.

## 7. Не делаем
